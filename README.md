# tpriyanshu90.github.io

Personal portfolio of **Priyanshu Tiwari** — Senior Backend Engineer (SDE II @ Amazon), distributed systems, search & applied AI.

Live at **https://tpriyanshu90.github.io**

## Stack

Plain static site — no build step:

- `index.html` — content
- `styles.css` — design (dark / light themes, responsive)
- `script.js` — theme toggle, mobile menu, scroll reveal, back-to-top
- `assets/` — images

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Deploy

Pushing to `main` publishes via GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
